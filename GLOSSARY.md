# Rides dashboard

Daily ride counts for a set of cities, summarised for reading at a glance.

## Language

**Ride count**:
The number of rides one city recorded on one day.
_Avoid_: Trips, volume, ridership

**Busiest day**:
A day on which a city's ride count equals its highest in the data. A city has more than one busiest day when that highest count repeats.
_Avoid_: Peak day, top day, best day
